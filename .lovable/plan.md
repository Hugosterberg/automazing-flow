

# Automazing – Automationsverktyg

## Koncept
En snygg, mörk webapp för att automatisera vardagliga arbetsuppgifter. Börjar med en polerad UI och Social Media som första funktionsområde.

---

## Design & Tema
- **Mörkt tema** inspirerat av Strike.me – svart bakgrund, vita texter, subtila glow-effekter på knappar och kort
- Animerade hover-effekter och mjuka transitions
- Modern sans-serif typografi
- Gradient-accenter (subtil vit/grå glow) på interaktiva element

## Layout
- **Sidebar-navigation** med ikoner för varje automationsområde (Social Media, E-commerce, Calendar)
- Minimalistisk header med "Automazing"-logotyp
- Huvudinnehåll till höger som ändras beroende på vald flik

## Flik 1: Social Media (huvudfokus)
- **Dashboard-vy** med översikt: schemalagda inlägg, statistik-kort, senaste aktivitet
- **Schemaläggare**: formulär för att skapa och schemalägga inlägg (med datum/tid-väljare)
- **Content-idéer**: lista med AI-genererade förslag (mockad data)
- **Statistik-kort**: engagement, followers, inlägg denna vecka (mockad data)

## Flik 2 & 3: E-commerce & Calendar
- Placeholder-sidor med "Coming soon"-design som matchar temat
- Ikoner och kort beskrivning av kommande funktioner

## Startsida / Landing
- Hero-sektion med Automazing-branding och kort tagline om automation
- Snabb access till de tre områdena via kort med glow-effekt
